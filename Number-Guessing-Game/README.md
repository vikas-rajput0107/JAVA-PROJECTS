# Java Number Guessing Game

A simple and interactive command-line game written in Java where the player tries to guess a randomly generated number within a minimum number of attempts.

## How It Works

1. The program generates a random natural number between 1 and 100.
2. The user is prompted to enter a guess.
3. The game provides hints indicating whether the guessed number is too high or too low.
4. The loop continues until the user guesses the correct number.
5. The game congratulates the user and displays the total number of attempts taken.

## How to Run

1. **Prerequisites:** Ensure you have the Java Development Kit (JDK) installed on your system.
2. **Download:** Ensure the `num_guess_game.java` file is downloaded to your local machine.
3. **Compile:** Open your terminal or command prompt, navigate to the folder containing the file, and compile the code using:
   ```bash
   javac num_guess_game.java
   ```
4. **Execute:** Run the compiled Java program using:
   ```bash
   java num_guess_game
   ```
